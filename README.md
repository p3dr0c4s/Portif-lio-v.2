# Portfólio do Pedro Henrique

Um site para conhecer meus projetos, minhas habilidades e um pouco do que estou aprendendo.

## O que tem por aqui?

- **Projetos:** cartões com links para abrir meus trabalhos no GitHub.
- **Sobre mim:** uma apresentação rápida e meus níveis atuais de conhecimento.
- **Tema claro e escuro:** escolha o visual que preferir.
- **Vitrola 8-bit:** uma mini vitrola com dez melodias originais tocadas pelo próprio navegador.
- **Contato:** links para falar comigo por e-mail, WhatsApp ou GitHub.

## Como abrir

1. Baixe ou clone este repositório.
2. Abra `index.html` no navegador.
3. Para testar a lista do GitHub com mais consistência, abra a pasta com um servidor local, como a extensão **Live Server** do VS Code.

Não é preciso instalar dependências nem fazer uma etapa de compilação.

## Arquivos principais

- `index.html` — conteúdo e estrutura do site.
- `style.css` — aparência, temas e adaptação para telas menores.
- `script.js` — projetos, filtros, contatos, animações e vitrola.
