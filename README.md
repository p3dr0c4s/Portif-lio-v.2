# Portfólio de Pedro Henrique

Site pessoal para reunir alguns projetos, experiências de interface e experimentos feitos por curiosidade e estudo.

O portfólio também funciona como um espaço para apresentar meu trabalho com front-end e deixar um canal aberto para conversas sobre novos projetos.

## Tecnologias

- HTML
- CSS
- JavaScript

## Estrutura

- `index.html`: estrutura e conteúdo da página
- `style.css`: estilos, temas e responsividade
- `script.js`: projetos, contatos, tema e integração com o GitHub

## Como executar

O projeto não precisa de dependências ou processo de build. Basta abrir o arquivo `index.html` no navegador.
